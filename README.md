## ⚡ [ Vision ]

O **REX** é um dashboard pessoal e minimalista que combina uma estética espacial com um player de áudio integrado. Desenvolvido para ser uma interface limpa, ele utiliza partículas interativas em neon verde e um design focado em tipografia e transparência.

> **"Space is not the final frontier, it's just the background."**

---

## 🎨 [ Visual Style ]

* **Background:** Motor de partículas `tsParticles` configurado com 1500+ pontos em `#00ff15`.
* **Typography:** Uso da fonte `Unbounded` para títulos e `Courier New` para elementos de sistema.
* **UI Components:** * Botões sociais com colchetes estilizados: `[ Discord ]`, `[ Spotify ]`, `[ Steam ]`.
    * Player de áudio com barra de progresso ultra-fina e capas circulares rotativas.

---

## 🚀 [ Features ]

- [x] **Ambient Background:** Partículas verdes interativas que não interferem no desempenho do áudio.
- [x] **Clean Audio Player:** Suporte para múltiplas faixas com troca de capas e nomes de música.
- [x] **Cyberpunk UI:** Links sociais com efeitos de hover em neon e separadores minimalistas.
- [x] **Optimized Rendering:** Uso de `React.memo` para evitar que as partículas "saltem" durante o play.

---

## 🛠️ [ Tech Stack ]

* **Framework:** React (Vite)
* **Icons:** `react-icons/fa`
* **Particles:** `@tsparticles/react` & `@tsparticles/slim`
* **Styling:** Custom CSS (Flexbox & Animations)
